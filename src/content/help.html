02 / YOUR LIBRARY

Your folders are already your projects.

A source is a parent directory. Its immediate child folders become projects. For example, add D:\Projects to see D:\Projects\Website and D:\Projects\Brand in your library.

  1. Open Settings → Project sources, or the Sources step in onboarding.
  2. Choose a folder with the + button, or enter its full path. Repeat for additional sources.
  3. Refresh to discover newly added folders. Hidden/system directories and directory links are skipped.

Sources cannot overlap. Disconnect a source to keep it saved but inactive; reconnect it later. Offline drives remain in the library. Removing a source removes its library/index records, while its files remain on disk.

Make the library yours

Use project actions to set a display name or emoji, client, tags, folder color, pin, or hide. Labels are stored in the app; folder names stay the same.

Find the right project

Filter by name, alias, client, tags or path. Sort the dashboard by recent activity, name or folder update. Group the sidebar by source, fold groups and resize the sidebar.

03 / A CONSISTENT START

Build a structure you’ll want to reuse.

Templates create folders and starter text files in a new project. In onboarding, select a saved template or choose Create a template. Your selection becomes the default in the New project dialog. Manage saved templates later in Settings → Project templates.

  1. Name. Give the template a recognizable name.
  2. Folders & files. Add one relative folder per line; use / for nesting. Add starter files with a path and content. Watch the live tree update.
  3. Protect. Click the shield beside a file or folder to move it under Secure/. Click again to move it out.
  4. Save or continue. Save a template to add more, or continue to save and use it by default for future projects.

Starter files can contain {{name}} and {{client}}; these are replaced when a project is created. Use New project or Ctrl Shift N, choose a source, name, client and template, then create it. Editing a template affects future projects.

What “Secure” means. Secure folders are excluded from content indexing, the inspector and app AI context by default. Explicit AI inclusion needs approval. This is an app privacy convention, not encryption or a filesystem permission. External tools and provider CLIs use their own access rules. Never put real credentials into reusable starter-file contents.

05 / FIND WHAT MATTERS

Search across your library, or just one project.

Settings → Search & indexing contains language/framework exclusion presets, custom folder/file patterns, optional nested .gitignore handling, project statistics, clearing and reindexing. Use project-relative paths or globs such as node_modules or *.log.

Indexing is incremental and only runs while the app is open. Secure folders, environment files, keys and credential-like content stay out by default. Clearing an index deletes cached records and pauses that project until you reindex it; project files are untouched.

06 / OPTIONAL AI

Choose where your AI requests go.

Configure AI in onboarding or Settings → AI connection. Your project context is sent when you use an AI action. Connection checks fetch provider model catalogs. Search, editing and library organization work without AI.

Provider Connection Models
Codex Install the supported CLI and sign in through the app’s provider action. Choose from its available catalog or provider default.
Cursor Install the supported CLI and sign in through the app’s provider action. Choose from available models or provider default.
Claude Code Install Claude Code and use its CLI sign-in. It opens in its own terminal. Use /model in Claude Code. It is a native launcher; it is not an in-app Assistant/Inspector model.

Unsloth Available in Settings under Custom providers, with its own endpoint and credential. Refresh its model catalog after saving the server URL.

Connect a local or custom endpoint

  1. Start the server and load a model.
  2. Select LM Studio or Custom. Enter its endpoint URL or IP:port. Onboarding adds /v1 when there is no path.
  3. Paste an API key if needed; leave it blank for a server without authentication. When reconfiguring, blank keeps an existing key. Choose the remove-key checkbox to connect without it.
  4. Select Save & test connection. The app saves the endpoint and automatically fetches models, showing success or a useful error.
  5. Choose a model and continue. For in-app providers, onboarding applies the choice to project/global Assistants and Inspector. Each surface can later use its own model picker.
HTTP is allowed for loopback servers such as localhost or 127.0.0.1. Other hosts require HTTPS. Do not put keys in URLs. API keys live in Windows Credential Manager; provider CLIs handle their own authentication. Use Check connection after returning from a sign-in window.
07 / A CONVERSATION WITH CONTEXT

Ask about your project, with controlled access.

The global Assistant sees the project catalog. A project’s Assistant tab works in that project and can be pinned alongside Files. Choose the provider/model, then type a message. Enter sends; Shift Enter adds a line.

In the global Assistant, use + to add more context to a request. Select Relevant docs from all projects for automatic workspace-wide context. For precise context, expand one or more projects and select their README/PROJECT overview, Docs folder, or exact files and subfolders. Your selections appear above the message box and can be removed before sending. Excluded or sensitive paths ask for permission before anything is shared. With no selection, only the full project catalog is included.

Attach files and folders from the explorer, by drag-and-drop, or with @path / /path. CSV, XLSX and DOCX are attached as extracted text. Source snapshots are saved with the message and can be reused in follow-ups; delete the message or chat to remove them.

Choose an access mode

Read only: proposed writes wait for Approve once.
Write: ordinary text changes may apply; protected paths ask.
Full: broader project writes and explicit source inclusion, confined to the current project.

Stay in control

Excluded sources and credential-like content require explicit approval. App AI writes are revision-checked UTF-8 text changes inside the project. They do not run shell commands. Provider CLIs have their own access behavior.

Chats are kept per scope and survive a restart. Archive a conversation to put it away; delete it when you want it removed.

08 / FROM FOLDERS TO UNDERSTANDING

Meet the project inspector.

Open a project’s Overview and look for the Project inspector button with the scan/search icon.

  2. Review the exact context before sending it. Choose a configured in-app AI provider and prompt profile.

09 / DOCUMENT UNDERSTANDING

Turn Word pages into readable Markdown.

Normal DOCX previews extract structure locally. Visual Word parsing is a separate, optional AI operation for documents where page layout matters.

  1. Install Microsoft Word or LibreOffice for local document rendering.
  2. Open a DOCX and choose the visual parsing action. Select a vision-capable model at LM Studio, Unsloth or a Custom endpoint.
  3. The app renders a private temporary PDF and sends one page image at a time to the chosen model.
  4. Stop or resume when needed, then copy the Markdown or save it beside the source.

The original document is not modified; macros and automatic link updates are disabled during rendering. Parsing can misread complex layouts. Compare important output with the original.

10 / YOUR EXISTING TOOLKIT

Keep the tools you already use.

Tools & launchers

Open Explorer, Command Prompt or PowerShell in a project or nested folder. Settings → Tools & launchers detects Cursor, Claude and Codex; enable desktop and CLI variants separately.

Custom tools use an executable and JSON argument list. {{project}} becomes the project-path argument. Example: ["{{project}}"].

Git at a glance

The Git tab shows the branch, bounded status and recent commits. Install Git for Windows and use projects whose folder is the repository root. Perform commits, pushes and branch changes in your Git tools.

Cursor workspace integration

In Settings → Integrations, create a connection to a Cursor dashboard.projectData file (JSONC is supported). Its groups appear in a separate sidebar workspace with names, paths, colors and availability. Registered projects open in the app; other folders open in Explorer. Integration content is kept separate from the library index.

12 / WHEN YOU NEED A HAND

Your data, and common fixes.

Where does the app keep my data?

The local library lives at %APPDATA%\ba.reflect.foldory\workspace.sqlite3. It stores sources, labels, templates, settings, chats and the search index. Provider sign-ins and preferences can also use app-managed files. API keys are in Windows Credential Manager. Project files remain in their original folders; PROJECT.md travels with the project.

How do I back up or use a different data directory?

Close the app before backing up its app-data directory. Back up your actual project folders separately. Set FOLDORY_DATA_DIR to an absolute path before launch for an independent library; it does not migrate an existing one. The app does not provide cloud sync or shared accounts.

My projects or drive disappeared.

Check Settings → Project sources. Reconnect disconnected sources, attach an offline drive and refresh. Select the parent containing your project folders; sources list immediate child folders, not every nested folder.

Search cannot find a file.

Confirm the project source is connected, inspect exclusions and .gitignore rules, then reindex the project. A cleared project index stays paused until reindexed. Secure and sensitive content may be intentionally excluded.

The AI model list is empty or authentication failed.

For local endpoints, start the server, load a model, check the API prefix and key, then Save & test again. Other hosts need HTTPS. For Codex/Cursor/Claude, install the supported CLI, sign in and Check connection after returning. A reachable server can still return an empty list; enter its model ID if known. AI setup can always be skipped.

A file save reports a conflict or failure.

A conflict means the disk file changed after it was read. Reload it to keep external changes, or deliberately overwrite it. On failure, keep the editor open, check drive availability and permissions, and retry; the app retains your local draft.

The inspector cannot save its draft.

Review and approve the separate native save confirmation. If PROJECT.md changed after scanning, scan and generate a fresh draft. Configure a supported in-app provider and model first; Claude Code is used in its own terminal.

The desktop app will not open on a fresh Windows installation.

Foldory requires Windows 10/11 x64 and Microsoft Edge WebView2 Runtime. Setup, or the standalone app’s first-run prompt, offers to install a missing runtime. The download needs internet access. Retry the runtime installation if it fails; device policy may require administrator assistance.

Can I delete a project from the dashboard?

There is no dashboard action that deletes a whole project from disk. Hide it or remove/disconnect its source to adjust the library. File and folder deletion inside the Files view is a separate operation and can affect disk contents.

Foldory is a local workspace, not an encrypted vault or a backup service. Its protections apply to app operations. Keep separate backups and use your operating system’s protections for sensitive files.
